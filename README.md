# وب‌سایت شخصی جواد امیری

## فایل‌ها
- `index.html` — کل سایت (HTML + CSS + JS) در یک فایل، بدون نیاز به بیلد یا نصب چیزی.
- `robots.txt`, `sitemap.xml` — برای سئو. آدرس `javadamiri.com` را در هر دو فایل و در `<meta>`های داخل `index.html` با دامنه واقعی جایگزین کنید.

## چطور محتوا را ویرایش کنم؟
تقریباً تمام محتوای قابل‌تغییر (مهارت‌ها، رزومه/تایم‌لاین، دوره‌ها، پروژه‌ها، دستاوردها، نظرات، شبکه‌های اجتماعی) در یک آبجکت به نام `SITE_DATA` در انتهای فایل `index.html` (داخل تگ `<script>`) قرار دارد. کافی است مقادیر داخل `[ ]` را با اطلاعات واقعی جایگزین کنید — نیازی به تغییر در HTML یا CSS نیست.

موارد زیر هم به‌صورت مستقیم داخل HTML قرار دارند و باید جایگزین شوند:
- تصویر پرتره در بخش «درباره من» (فعلاً یک جای‌نگهدار با حروف اول اسم است).
- ایمیل، شماره تماس و موقعیت مکانی در بخش تماس.
- لینک‌های واقعی شبکه‌های اجتماعی در `SITE_DATA.socials`.
- تصویر Open Graph (`og:image`) برای پیش‌نمایش در شبکه‌های اجتماعی.

## فرم تماس
فرم دارای اعتبارسنجی کامل سمت کاربر است، اما چون سایت فعلاً بک‌اند ندارد، پس از تایید فرم یک لینک `mailto:` باز می‌شود تا کاربر پیام را از طریق ایمیل خودش ارسال کند. برای ارسال واقعی و خودکار فرم (بدون باز شدن ایمیل کاربر)، باید فرم را به یک سرویس مانند Formspree، یک API اختصاصی، یا ایمیل سرور متصل کنید.

## انتشار
این یک سایت استاتیک است؛ کافی است پوشه را روی هر سرویس میزبانی استاتیک (مثل Netlify, Vercel, GitHub Pages یا هر هاست معمولی) آپلود کنید. نیازی به Node.js یا فرآیند Build نیست.
