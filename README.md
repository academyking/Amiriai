# Javad Amiri — Personal Brand Website

سایت شخصی RTL با تم مشکی/طلایی، انیمیشن‌های سبک، شبکه عصبی Canvas، نریشن اختیاری مرورگر، Responsive و داده‌های قابل ویرایش.

## اجرا
فایل `index.html` را باز کنید یا پروژه را روی هر Static Host قرار دهید.

## ویرایش اطلاعات واقعی
فایل `assets/js/data.js` منبع اصلی اطلاعات است. موارد `PLACEHOLDER` را فقط با داده‌های واقعی جایگزین کنید.

## تصویر پرتره
در `index.html` بخش `portrait-placeholder` را با تگ تصویر واقعی جایگزین کنید. برای عملکرد بهتر، تصویر را WebP/AVIF و با ابعاد متناسب آماده کنید.

## فرم تماس
در `assets/js/app.js`، handler فرم را به endpoint واقعی (مثلاً API/Serverless Function) متصل کنید. در حالت فعلی، فرم فقط Validation سمت مرورگر دارد و هیچ اطلاعاتی را به سرویس خارجی ارسال نمی‌کند.

## SEO
عنوان، توضیحات، Open Graph پایه و ساختار Semantic آماده است. پس از مشخص شدن دامنه، `canonical`، `og:url`، `sitemap.xml` و `robots.txt` را با دامنه واقعی تکمیل کنید.
